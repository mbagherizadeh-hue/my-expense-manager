# مدیریت هزینه‌های من

برنامه‌ی ساده‌ی مدیریت هزینه‌های شخصی با HTML، CSS و JavaScript خالص. بدون نیاز به build، بدون وابستگی. داده‌ها در LocalStorage مرورگر ذخیره می‌شوند.

## اجرا روی کامپیوتر
فایل `index.html` را مستقیم در مرورگر باز کنید. (فونت وزیرمتن از اینترنت بارگذاری می‌شود؛ بدون اینترنت از فونت‌های سیستم استفاده می‌شود.)

## آپلود در GitHub
```bash
git init
git add .
git commit -m "مدیریت هزینه‌های من"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

## استقرار در Vercel
۱. در vercel.com وارد شوید و **Add New → Project** را بزنید.
۲. مخزن GitHub را انتخاب کنید.
۳. Framework Preset را روی **Other** بگذارید، Build Command و Output Directory را خالی رها کنید و **Deploy** را بزنید.

## نکته
داده‌ها فقط در همین مرورگر و همین دستگاه ذخیره می‌شوند؛ با پاک‌کردن اطلاعات مرورگر از بین می‌روند.
